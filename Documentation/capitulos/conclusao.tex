\chapter{CONCLUSÃO}

\hspace{0.5cm} A solução entregue responde com consistência à pergunta proposta pelo \tipotrabalho:
um sistema que compreende a jornada do cliente, modela os processos de negócio e toma decisões técnicas
fundamentadas. Todavia, há uma limitação reconhecida: a ausência de testes automatizados, a validação
de endpoints foi realizada manualmente via Insomnia.

Apesar disso, o projeto atendeu aos requisitos funcionais e não funcionais estabelecidos,
demonstrando todo o trajeto comum de uma aplicação de Food Service, desde a gestão de produtos, catálogo,
funcionários, clientes, pedidos, até a entrega.

O desenvolvimento do \tipotrabalho\ proporcionou uma experiência prática valiosa,
permitindo a aplicação de conceitos teóricos em um cenário realista.
