\section{Gestão de Lojas}

\subsection{\texttt{POST /api/v1/stores}}

\noindent\textbf{Finalidade}: Criar uma nova loja

\noindent\textbf{Permissão}: JWT | Perfil: Admin

\noindent\textbf{Body}\footnote{Para fins de teste, é usado a biblioteca Faker para gerar dados aleatórios.}:
Todos os campos são obrigatórios exceto \texttt{complement}

\vspace{-0.2cm}

\begin{minted}{json}
{
  "phone": "{% faker 'randomPhoneNumber' %}",
  "cep": "22775056",
  "complement": "10"
}
\end{minted}

\noindent\textbf{Status Codes}: 201, 403, 422

\begin{tcolorbox}[colback=green!5, colframe=black, title=\textbf{201 Created}]
\begin{minted}{json}
{
  "created_at": 1777558556,
  "phone": "+5521910276281",
  "deleted_at": null,
  "address": {
    "cep": "22775-056",
    "state": "RJ",
    "city": "Rio de Janeiro",
    "neighborhood": "Barra da Tijuca",
    "street": "Avenida José Silva de Azevedo Neto",
    "complement": "10"
  },
  "id": "069f3641-c09e-7731-8000-b04e75d39158",
  "updated_at": 1777558556
}
\end{minted}
\end{tcolorbox}

\subsection{\texttt{GET /api/v1/stores}}

\noindent\textbf{Finalidade}: Listar todas as lojas

\noindent\textbf{Permissão}: JWT | Perfis: Admin

\noindent\textbf{Body}: Nenhum campo é necessário

\noindent\textbf{Query Parameters}: \texttt{page} e \texttt{page\_size}

\noindent\textbf{Status Codes}: 200, 403, 422

\begin{tcolorbox}[colback=green!5, colframe=black, title=\textbf{200 OK}]
Para fins de visualização breve, a loja criada anteriormente está listada truncada.

\subsection{\texttt{PATCH /api/v1/stores/:store\_id}}

\noindent\textbf{Finalidade}: Atualizar os detalhes de uma loja específica

\noindent\textbf{Permissão}: JWT | Perfil: Admin

\noindent\textbf{Body}: Todos os campos são opcionais

\vspace{-0.2cm}

\begin{minted}{json}
{
  "phone": "{% faker 'randomPhoneNumber' %}"
}
\end{minted}

\noindent\textbf{Status Codes}: 200, 403, 404, 422

\begin{tcolorbox}[colback=green!5, colframe=black, title=\textbf{200 OK}]
Para fins de visualização breve, é mostrada apenas os campos atualizados.
\begin{minted}{json}
{
  "phone": "+5521979251835",
  "updated_at": 1777972705,
  "id": "069f3640-e1bc-7fa2-8000-a6059a7ab69a"
}
\end{minted}
\end{tcolorbox}

\subsection{\texttt{DELETE /api/v1/stores/:store\_id}}

\noindent\textbf{Finalidade}: Excluir uma loja por ID

\noindent\textbf{Permissão}: JWT | Perfil: Admin

\noindent\textbf{Body}: Nenhum campo é necessário

\noindent\textbf{Status Codes}: 204, 403, 404

\begin{tcolorbox}[colback=green!5, colframe=black, title=\textbf{204 No Content}]
Loja excluída com sucesso. Nenhum conteúdo é retornado.
\end{tcolorbox}
