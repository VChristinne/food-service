\section{Autenticação de Usuários}

\subsection{\texttt{POST /api/v1/auth/login}}

\noindent\textbf{Finalidade}: Autenticar usuários

\noindent\textbf{Permissão}: Público

\noindent\textbf{Body}: Todos os campos são obrigatórios

\vspace{-0.2cm}

\begin{minted}{json}
{
  "email": "christinne@raizesnordeste.com",
  "password": "12345678!A"
}
\end{minted}

\noindent\textbf{Status Codes}: 200, 401, 422

\begin{tcolorbox}[colback=green!5, colframe=black, title=\textbf{200 OK}]
Para fins de formatar a resposta, o token foi truncado.
\begin{minted}{json}
{
  "id": "069d510e-a565-7add-8000-65391d41016c",
  "access_token": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...",
  "token_type": "Bearer"
}
\end{minted}
\end{tcolorbox}

\subsection{\texttt{POST /api/v1/auth/logout}}

\noindent\textbf{Finalidade}: Encerrar sessão do usuário

\noindent\textbf{Permissão}: JWT | Perfis: Todos os usuários autenticados

\noindent\textbf{Body}: Nenhum campo é necessário

\noindent\textbf{Status Codes}: 200, 401

\begin{tcolorbox}[colback=green!10, colframe=black, title=\textbf{200 OK}]
Logout simulado, num cenário real seria necessário uma blacklist de tokens. \\
Todos os tokens expiram em 1 hora.

\begin{minted}{json}
{ "message": "Logout successful" }
\end{minted}
\end{tcolorbox}
