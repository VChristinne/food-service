\section{Requisitos Funcionais}

\begin{itemize}
  \item \textbf{RF1: Autenticação e Cadastro de Usuários}

  O sistema deve permitir o cadastro e autenticação de clientes e funcionários, com regras específicas para cada tipo de usuário.
  Cada perfil possui autenticação via JWT e gerenciamento de sessão, garantindo segurança e controle de acesso.

  \textbf{Clientes:}
  \begin{itemize}[topsep=0pt, itemsep=0pt]
    \item Cadastro com dados pessoais (nome, email, senha, telefone e endereço);
    \item Email único no sistema;
    \item Login com email e senha;
    \item Logout com invalidação de sessão;
    \item Aceite de políticas de privacidade e termos de uso (LGPD).
  \end{itemize}

  \textbf{Funcionários:}
  \begin{itemize}[topsep=0pt, itemsep=0pt]
    \item Cadastro realizado apenas por administradores;
    \item Login com email e senha (domínio @raizesnordeste.com);
    \item Logout com invalidação de sessão;
    \item Registro de todo cadastro e acesso em log de auditoria (quem, quando, ação).
  \end{itemize}
\end{itemize}

\begin{itemize}
  \item \textbf{RF2: Inventário de Ingredientes}

  O sistema deve gerenciar um inventário de ingredientes utilizados na preparação dos alimentos, permitindo controle de estoque e planejamento de compras.

  \begin{itemize}[topsep=0pt, itemsep=0pt]
    \item Cadastro de ingrediente (ID, nome, quantidade, quantidade mínima e medida de unidade);
    \item Consulta de ingredientes disponíveis;
    \item Atualização dos dados do ingrediente;
    \item Consulta da data de cadastro e última atualização de cada ingrediente;
    \item Consulta de ingredientes abaixo da quantidade mínima para alerta de reposição (opcional, documentado).
  \end{itemize}
\end{itemize}

\begin{itemize}
  \item \textbf{RF3: Gestão de Cardápio}

  O sistema deve permitir a criação e gerenciamento de um cardápio, associando cada refeição a uma lista de ingredientes necessários para sua preparação.

  \begin{itemize}[topsep=0pt, itemsep=0pt]
    \item Cadastro de refeição (ID, nome, disponibilidade, preço e associação com ingredientes);
    \item Consulta de refeições disponíveis no cardápio;
    \item Atualização dos dados da refeição;
    \item Consulta dos ingredientes necessários para cada refeição;
    \item Consulta da data de cadastro e última atualização de cada refeição;
    \item Consulta de refeições que utilizam um ingrediente específico (opcional, documentado).
  \end{itemize}
\end{itemize}

\begin{itemize}
  \item \textbf{RF4: Realização e Gestão de Pedidos}

  Pedidos registram itens solicitados, valores, status de preparo e canal de origem. \\
  Fluxo completo: pendente $\rightarrow$ em preparo $\rightarrow$ pronto $\rightarrow$ entregue ou cancelado.

  \begin{itemize}[topsep=0pt, itemsep=0pt]
    \item Criação de pedido com múltiplos itens (produto, quantidade, preço unitário);
    \item Registro obrigatório de canal de origem (app, totem, balcão, delivery, web);
    \item Cálculo automático de valor total com taxa de serviço (10\%);
    \item Atualização de status (pendente, preparando, a caminho, entregue, falhou);
    \item Cancelamento de pedido (com restrições por status);
    \item Consulta e filtragem de pedidos por cliente, unidade ou canal;
    \item Integração com serviço de pagamento (mock) no fluxo de confirmação.
  \end{itemize}
\end{itemize}

\begin{itemize}
  \item \textbf{RF5: Programa de Fidelização}

  Sistema de pontos para incentivar a recompra e premiar clientes, integrado ao processo de pedidos.

  \begin{itemize}[topsep=0pt, itemsep=0pt]
    \item Acúmulo de pontos por pedido realizado (proporção ao valor gasto);
    \item Consulta de saldo de pontos do cliente;
    \item Resgate de pontos para desconto em pedido futuro;
    \item Consentimento explícito do cliente para participar do programa;
    \item Histórico de transações de pontos (acúmulo e resgate);
    \item Definição de regras de conversão (1 real = 1 ponto).
  \end{itemize}
\end{itemize}

\begin{itemize}
  \item \textbf{RF6: Auditoria e Rastreabilidade}

  Registro centralizado de ações sensíveis para rastreabilidade operacional e conformidade.

  \begin{itemize}[topsep=0pt, itemsep=0pt]
    \item Log de operações administrativas referentes a funcionários (cadastro, acesso);
    \item Log de operações de clientes (cadastro, acesso, pedidos);
    \item Log de criação, atualização e cancelamento de pedidos;
    \item Identificação de autor (usuário), timestamp, ação, recurso afetado e user-agent;
    \item Persistência em banco de dados para consulta posterior.
  \end{itemize}
\end{itemize}
