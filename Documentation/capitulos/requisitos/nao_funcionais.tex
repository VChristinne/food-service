\section{Requisitos Não Funcionais}

\begin{itemize}
  \item \textbf{RNF1: Segurança}

  A segurança dos dados e das operações é fundamental para proteger informações sensíveis e garantir a integridade do sistema.

  \begin{itemize}[topsep=0pt, itemsep=0pt]
    \item Criptografia de senhas usando SHA-256-crypt;
    \item Validação obrigatória de JWT em endpoints protegidos;
    \item Token JWT codifica a função/role do usuário para autorização;
    \item Controle de acesso baseado em funções (role-based access control);
  \end{itemize}
\end{itemize}

\begin{itemize}
  \item \textbf{RNF2: Multicanalidade}

  O sistema deve atender múltiplos canais de interação, mantendo coerência operacional.

  \begin{itemize}[topsep=0pt, itemsep=0pt]
    \item Disponibilização de API REST como interface principal;
    \item Suporte a múltiplos canais: App, Totem, Balcão e Web;
    \item Rastreabilidade de origem (canal) em todas as transações.
  \end{itemize}
\end{itemize}

\begin{itemize}
  \item \textbf{RNF3: Auditoria e Rastreabilidade}

  Registro centralizado de operações críticas para conformidade e investigação.

  \begin{itemize}[topsep=2pt, itemsep=2pt]
    \item Logging de operações críticas de autenticação;
    \item Logging de todas as operações de estoque;
    \item Logging de operações de venda;
    \item Logging de ações administrativas e de funcionários;
  \end{itemize}
\end{itemize}

\begin{itemize}
  \item \textbf{RNF4: Performance e Disponibilidade}

  O sistema deve ser responsivo em cenários de alto uso e escalável para crescimento.

  \begin{itemize}[topsep=0pt, itemsep=0pt]
    \item Capacidade de lidar com horários de pico (almoço e jantar);
    \item Arquitetura preparada para escalabilidade horizontal (adicionar servidores);
    \item Tolerância a falhas em integrações externas (ex: pagamento mock).
  \end{itemize}
\end{itemize}

\begin{itemize}
  \item \textbf{RNF5: Lei Geral de Proteção de Dados (LGPD)}

  Conformidade com a legislação brasileira de proteção de dados pessoais.

  \begin{itemize}[topsep=0pt, itemsep=0pt]
    \item Direito ao esquecimento: cliente pode solicitar exclusão de dados pessoais;
    \item Registro de consentimento do usuário ao aceitar políticas de privacidade e LGPD;
    \item Minimização de dados: coleta apenas do necessário (nome, email, telefone, endereço);
    \item Retenção limitada: dados pessoais são mantidos apenas enquanto necessário para a finalidade;
    \item Não exposição de dados sensíveis em respostas de API (ex: senhas sem hash, tokens internos).
  \end{itemize}
\end{itemize}
