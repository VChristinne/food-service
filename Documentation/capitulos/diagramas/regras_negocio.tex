\section{Regras de Negócio}

\hspace{0.5cm} As regras de negócio definem as diretrizes e restrições que governam o funcionamento do sistema.
São essenciais para garantir que o sistema atenda aos requisitos do negócio e opere de maneira eficiente e segura.

A seguir, estão descritas as principais regras de negócio para cada área do sistema.

\subsection{Autenticação e Autorização}
\label{subsec:auth}

\begin{enumerate}[topsep=1pt, itemsep=0pt]
  \item JWT Token com validade de 24 horas
  \item Papéis: admin, gerente, chef, garçom, entregador
  \item Restrição de acesso por loja e papel
\end{enumerate}

\subsection{Gestão de Clientes}
\label{subsec:client}

\begin{enumerate}[topsep=1pt, itemsep=0pt]
  \item Aceite obrigatório de LGPD
  \item Exclusão de dados com soft delete
  \item Pontos de fidelidade: 1 ponto por real gasto
\end{enumerate}

\subsection{Gestão de Funcionários}
\label{subsec:employee}

\begin{enumerate}[topsep=1pt, itemsep=0pt]
  \item Apenas admin cria funcionários
  \item Associação obrigatória a loja (exceto admin)
  \item Exclusão de dados com soft delete
\end{enumerate}

\subsection{Gestão de Lojas}
\label{subsec:store}

\begin{enumerate}[topsep=1pt, itemsep=0pt]
  \item Apenas admin cria lojas
  \item Associação de gerente obrigatório
  \item Gerente adiciona funcionários à loja
\end{enumerate}

\subsection{Catálogo de Pratos}
\label{subsec:catalogue}

\begin{enumerate}[topsep=1pt, itemsep=0pt]
  \item Apenas gerente cria e gerencia pratos
  \item Preço obrigatório e positivo
  \item Gestão de ingredientes via inventário
\end{enumerate}

\subsection{Gestão de Inventário}
\label{subsec:inventory}

\begin{enumerate}[topsep=1pt, itemsep=0pt]
  \item Apenas gerente gerencia inventário
  \item Redução automática ao criar pedido
  \item Associação com múltiplos pratos
\end{enumerate}

\subsection{Pedidos}
\label{subsec:order}

\begin{enumerate}[topsep=1pt, itemsep=0pt]
  \item Apenas clientes autenticados
  \item Validação de existência de pratos e ingredientes
  \item Cálculo de preço com taxa de 10\%
  \item Cálculo de pontos: (total com taxa) x 1
  \item Tipos: dine\_in, takeaway, delivery
  \item Canais: app, totem, counter, web
  \item Métodos de pagamento: cash, credit\_card, pix, vale\_alimentacao
\end{enumerate}

\subsection{Auditoria}

\begin{enumerate}[topsep=1pt, itemsep=0pt]
  \item Todas ações registradas (create, read, update, delete, login, logout, password\_change)
  \item Informações: action, entity\_type, entity\_id, user\_id, timestamp, details, ip\_address
  \item Não apagável (append-only)
  \item Acesso restrito a admin
\end{enumerate}
